Single-Axis Active Gimbal Stabilization System

Mechatronics I | Fall 2026

Status: In Development

Project Overview

This project focuses on designing a single-axis active stabilization platform using an Arduino UNO, MPU-6050 inertial measurement unit (IMU), and servo motor. The objective is to maintain the platform's orientation while its supporting structure is tilted.

Project Objectives

  • Measure platform orientation using an IMU.
  • Develop an Arduino feedback control algorithm.
  • Actuate a servo to correct angular displacement.
  • Evaluate stabilization accuracy and response.

Materials

  • Arduino UNO R3
  • MPU-6050 (GY-521)
  • SG90 Servo Motor
  • Breadboard and jumper wires
  • Cardboard

Minimum Viable Project (MVP)

Construct a functional one-axis platform that uses sensor feedback to maintain a level orientation.

Bonus Objectives

  • Accelerometer/gyroscope sensor fusion
  • PD or PID feedback control
  • Real-time telemetry and performance analysis
